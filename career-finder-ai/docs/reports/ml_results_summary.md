## Why Rubric-Assisted Metrics Are Not Honest

The training label `target_score` is a weighted sum of eight rubric component scores (`major_fit_score`, `skill_match_score`, etc.). Rubric-assisted models include those same components as inputs, so they can reconstruct the label (MAE ≈ 0.02, R² ≈ 1.0). That is **target leakage** — useful as a sanity check, not as reported model quality. See `docs/reports/model_metrics_summary.md`.

## Limitations

- **Synthetic profiles:** Test conversations are curated dataset profiles, not live user traffic.
- **Rubric-generated labels:** `target_score` comes from the same rubric as the live recommender, not from user clicks or hire outcomes.
- **No real user feedback:** Precision@k uses a fixed relevance threshold on rubric scores, not observed engagement.
- **Not production-integrated:** Fair models are trained and evaluated offline; `/recommend` still ranks by the rubric only.
